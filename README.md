# Çamaşır Makinesi Ruh Çağırma Protokolü

Bu depo, ev içi beyaz eşya diplomasisinin en ileri belgesidir.

## Nedir?

Çamaşır makineleri yıllardır tek çorap yutar. Bilim bunu "statik elektrik" diye geçiştirir. Biz geçiştirmiyoruz. Bu yazılım tamburun içindeki idari birimle **resmi yazışma** kurar.

## Kurulum

```bash
python3 protokol.py
```

Başka bir şey kurmanıza gerek yok. Ruh zaten evinizde.

## Kullanım

1. Makinenin kapağını kapatın (açıksa protokol ihlali olur).
2. Programı çalıştırın.
3. Sorunuzu sorun.
4. Gelen cevabı noter onaylı kabul edin.

## Yasal Uyarı

- Su basması bu yazılımın suçu değildir.
- Kayıp çorap iade edilmez, sadece açıklanır.
- Makine ruhu mesai saatleri dışında cevap vermeyebilir.

## Gizli Ek

Kodun içinde base64 bir satır vardır. Açarsanız küçük bir bürokrasi taşlaması çıkar. Parti logosu yoktur, afiş de yoktur. Sadece kaybolan şeyler üzerine bir cümle.
